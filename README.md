# 중랑비서실 · jungnang-secretariat

PI의 총괄 기획과 실행을 MSAVN(C)로 연결하는 재사용형 AI 스킬입니다. 공동 기획안 하나를 중심으로 역할별 작업을 나누고, 승인된 실행과 결과 확인, 주민 경험과 조직 학습까지 이어 갑니다.

공개 방법론과 빈 작업 양식만 담았습니다. 실제 일정·내부 의제·주민 정보·비공개 원문은 포함하지 않습니다. 중랑구의 공식 조직·지침을 선언하는 저장소가 아닙니다.

## 언제 사용하나요?

- 중랑비서실 또는 비서실 에이전틱 운영을 요청할 때
- PI 공동 기획, 메시지·일정·의제·비주얼·커뮤니티를 함께 설계할 때
- 네트워크와 조직역량을 실행 과제에 연결할 때
- 리더십 시그널을 실제 실행·확인·학습으로 이어 갈 때

단일 원고 교정이나 일반 뉴스 편집은 해당 전문 스킬을 우선합니다.

## MSAVN(C)

- M · Message: 정책과 행동으로 뒷받침하는 메시지
- S · Schedule: 준비·현장·후속을 연결하는 시점과 동선
- A · Agenda: 해결할 주민 문제, 선택과 결정, 후속 과제
- V · Visual: 현장과 제작물에서 실제로 보이고 경험되는 것
- N · Network: 사람·전문성·권한·자원·협업을 연결하는 조직역량
- C · Community: 참여·경청·응답·관계·주민 경험과 학습

N과 C는 내부/외부의 구분이 아닙니다. C의 괄호는 생략 허가가 아니며, 영향받는 주민과 응답 통로는 항상 확인합니다.

## 사용 방법

1. SKILL.md와 references 폴더를 함께 읽거나 사용하는 AI 도구의 스킬 등록 기능에 제공합니다.
2. 의제나 행사, 목적, 기한, 필요한 산출물, 허용된 실행 범위를 알려 줍니다.
3. 공동 기획 → 역할별 작업 → 결정·승인 → 실행 → 검증·학습 순서로 진행합니다.

스킬 호출을 지원하는 환경의 요청 예시:

“$jungnang-secretariat으로 이번 주민 간담회의 PI 공동 기획안을 만들어 주세요. 목적은 생활 불편의 확인과 후속 답변 체계 마련이며, 결과물은 공동 기획안과 역할별 준비 목록입니다. 우선 내부 초안까지 진행해 주세요.”

GitHub에 올리는 것만으로 Claude·GPT 등 각 도구에 설치되거나 자동 갱신되지는 않습니다. 각 환경에서 스킬 등록·반영 여부를 별도로 확인해야 합니다. 설치 자체가 상시 조직 배치·자율 운영·반복 예약을 뜻하지 않습니다.

## 승인과 공공성

읽기·조사·내부 기획·초안·검증은 허용된 범위에서 진행합니다. 게시·발송·초대·일정 변경·공유·접근 권한 변경은 해당 행동에 필요한 사용자 지시와 확인 절차를 충족한 후 실행합니다. 정책·예산·인사·공식 입장·새 약속은 권한 있는 사람이 결정합니다.

주민 개인정보를 최소화하고 공개 범위를 확인합니다. 실제 없는 성과·현장·발언을 만들지 않으며, 선거운동이나 정치 성향·인구특성별 맞춤 설득에 사용하지 않습니다.

## 파일 구성

- SKILL.md: 역할, 운영 원칙, 실행·확인 기준
- agents/openai.yaml: 지원 환경용 표시 이름과 호출 안내
- assets/icon.svg: 스킬 아이콘
- references/roles-workflow.md: 역할별 책임과 의존관계
- references/shared-templates.md: 공동 기획·위임·실행·승인·학습 양식
- references/source-basis.md: 원자료와 이 스킬의 확장 적용 구분

연계 전문 스킬은 별도로 준비해야 합니다. 이 저장소가 다른 스킬이나 기존 발행물을 자동 변경하지 않습니다.

별도 라이선스는 지정하지 않았습니다.
