# 출처와 적용 범위

이 스킬은 PI 방법론을 중랑비서실의 공동 기획·실행 방식으로 적용한 운영 설계다. 아래 원자료의 논의와 이 스킬의 확장·운영 설계를 구분한다. 역사적 자료의 인물·직책·정책·일정을 현재 중랑의 사실로 사용하지 않는다.

이 공개판에는 원자료 파일, 비공개 저장소 링크, 원문 접근 식별자를 포함하지 않는다. 직접 인용하거나 상세한 주장을 할 때에는 적법하게 접근할 수 있는 원문을 다시 확인한다.

## PI 기획 원자료

자료명: 「PI 기획 원자료」(제공 자료의 식별용 명칭).

- 슬라이드 23–25: 진정성에 관한 논의. 실제 정책·행동과 분리된 이미지 포장을 경계하는 기준.
- 슬라이드 31–32: 상황·개인 자산·정책·사람의 통찰에서 개념·전략을 거쳐 MSAV로 연결하는 흐름.
- 슬라이드 53: WPLAN의 공동 기획. 메시지·일정·의제·시각을 함께 설계하는 근거.
- 슬라이드 54: 분기와 의제의 연결. 방향과 시점을 함께 보는 기획 단위.
- 슬라이드 72: 실제 모습, 계획한 정체성, 받아들여지는 이미지의 겹침.

MSAVN(C) 전체가 이 원자료에 동일한 표기로 제시되었다고 주장하지 않는다. N과 C의 적용 근거는 아래와 구분한다.

## 『물음』의 PI·공동 기획·조직역량

자료명: 『물음』.

아래는 책 인쇄면 기준이다. 검토에 사용한 PDF의 페이지 번호는 인쇄면보다 1 크다. 원문을 인용할 때 문장·페이지를 다시 확인한다.

- 인쇄면 73: PI의 정의.
- 인쇄면 74: 리더십을 체계로 보는 설명.
- 인쇄면 76–77: 다음 주 일정, 동선, 의상, 메시지를 함께 기획하고 주간 검토로 되돌리는 방식.
- 인쇄면 141–144: 역할·교육·부서 간 자원과 조직 안팎의 지식 연결. 실행을 가능하게 하는 조직역량 논의.

책이 N=Network를 MSAV의 다섯 번째 글자로 명시했다고 확인된 것은 아니다. 조직역량 논의를 바탕으로 이 스킬에서 확장 적용한 정의와 구분한다.

## C의 별도 근거

자료명: 「C가 포함된 기획 자료」(제공 자료의 식별용 명칭, 페이지 번호 미확인).

해당 자료에서는 MSAV 네 영역과 별도의 다섯 번째 C를 구분한다. N과 C를 같은 글자의 다른 명칭처럼 합치지 않는다. 이 스킬은 C를 참여·응답·관계·경험·학습의 지속이라는 관점으로 운영한다. 정확한 원문 인용은 해당 위치 확인 후에만 한다.

## 이 스킬의 확장과 운영 설계

- 중랑비서실은 PI의 총괄 기획 및 실행을 맡는 운영 모델이다.
- N은 Network이며 “어떤 조직역량을 갖출 것인가?”를 다룬다. C와 겹치면서도 관점과 책임은 다르다.
- 총괄과 M/S/A/V/C 담당, 횡단 N 책임, 공동 기획안, 위임 계약, 실행 기록, 승인·의존관계 점검, 실행 후 학습을 연결한다.

이 세부 에이전트 구조와 양식은 이 스킬의 운영 설계다. 원자료의 직접 인용이나 중랑구의 공식 조직·지침으로 제시하지 않는다.

## 현행 명칭과 전문 스킬

리더십 발행물은 “중랑시그널 시리즈의 리더십 시그널”로 다룬다. 기존 자료의 ‘두부’ 명칭은 역사적 매체 맥락이나 보조 캐릭터를 뜻할 수 있으므로 문맥을 구분한다.

연결된 전문 스킬이 있으면 실제 내용을 읽고 적용한다. 공통 편집은 jungnang-signal, 기관 표현·디자인 검토는 jungnang-public-communication, 정책 설계는 agungi, 김현성 개인 문체는 kimhyunsung-writing을 사용한다. 설치되지 않은 스킬을 읽었다고 하거나 이 저장소가 다른 스킬을 자동으로 수정한다고 설명하지 않는다.
